# LoLKarmaBook 1.0.0 桌面与实时检测

桌面程序为 `LoLKarmaBook.exe`，使用 .NET 10 WPF，按当前 Windows 用户运行。Windows 安装包包含 .NET 运行时，默认目录为 `D:\LoLKarmaBook`，可在安装向导中更改；默认数据目录为程序目录下的 `userdata`。

## 页面与布局

界面采用暖米黄色背景、深棕正文和琥珀色强调。四个页面为「当前对局」「我的记录」「Hexdata 海斗分」「设置 / 关于」，可分别用 `Ctrl+1` 至 `Ctrl+4` 切换，`F5` 刷新当前页面。

- **当前对局**：顶部保留当前状态，「连接与对局详情」展开后显示诊断信息与连接操作。左侧名单显示本人、历史记录和当前选中对象；未选择玩家时显示操作引导，选择后展开类别、标签、备注和提醒有效期表单。保存按钮位于表单滚动区外，再遇提醒可以展开查看。
- **我的记录**：按状态、类别和事件时间筛选；筛选项随可用宽度换行。每条记录以玩家、类别/标签、时间和备注分层呈现，省略的内容可通过悬停查看。「编辑」直接显示，其他操作收在「更多」菜单中。反馈消息占用独立区域，不覆盖列表。
- **Hexdata 海斗分**：登录、查询指定游戏 ID 或自己的海斗分，查看本地查询记录、走势和对局详情。查询详情及双方名单中的玩家 ID 使用只读可选择文本，支持鼠标选择、`Ctrl+A` 和 `Ctrl+C`；复制文字不会触发查询记录的展开或收起。
- **设置 / 关于**：宽窗左侧排列数据位置、偏好和诊断，右侧排列快照恢复、数据保护和关于。两列独立布局，右列宽 360 DIP，列间与卡片间距 12 DIP；可用页面宽度小于 820 DIP 时改为单列。诊断日志默认折叠，展开后的日志区域最大高度为 180 DIP。

主窗口默认 1280 × 840，最小 980 × 660。布局尺寸使用 WPF 的 DIP 单位。

## 客户端连接与空间

`LoLKarmaBook.Client` 从正在运行的 `LeagueClientUx` 进程或客户端目录的 `lockfile` 发现本机连接参数，向回环地址发起只读 HTTPS 请求。生产 handler 禁用代理和重定向，使用内置 Riot 根证书验证客户端证书；连接令牌只驻留内存。

读取内容包括当前账号、平台、gameflow 阶段与名单。选人阶段读取 champion-select 会话，加载和游戏中读取 gameflow 会话。优先以 PUUID 建立稳定关联，缺失时使用带平台作用域的账号标识；名单未提供可用身份时不猜测稳定身份。连接状态区分未运行、无法获取参数、未登录、已连接和中断。

主窗口约每 2 秒串行检测一次，连接操作共享互斥门。账号身份派生独立笔记空间键，登录、注销、重连和对局阶段变化时重新评估。演示空间与真实账号隔离，点击「实时对局」返回当前账号。

同局刷新更新名单和提醒并保留编辑内容。跨局、跨账号和关闭时保护草稿；连接丢失时保留上下文并停止新记录。提醒交付使用 Core 的持久化收据，同局不重复提示。

## 记录与赛后卡片

记录包含玩家游戏 ID、类别、官方英雄/装备标签、备注和有效期。玩家 ID 在保存时写入，不因后续改名覆盖；标签搜索支持名称、别名与拼音等匹配。提醒有效期使用天数，`0` 为永久，默认值可在设置页调整。记录支持编辑、归档、撤回、发布草稿和删除。

名单在内存中以 `MatchRosterSnapshot` 保存。进入赛后阶段后，仅在历史查询命中已记录玩家时自动显示右下角卡片，展示再遇记录，并允许选择玩家、勾选类别和填写备注后保存。关闭卡片不会写入记录或消耗提醒收据；补记使用正常保存路径。游戏过程中不自动弹出该卡片。

最近完成的对局保留 20 分钟手动补记窗口。回到大厅或短暂断连不会立即清除该名单；在有效期内可点击「标记上一局」。到期后入口失效，账号切换按空间边界处理。

`FindRemindersAsync` 用于历史预览查询，不创建收据；`EvaluateRemindersAsync` 仅在选人、加载和游戏中交付提醒。

## Hexdata 海斗分

桌面页通过专用浏览器窗口完成 Hexdata 登录，用户返回程序后点击「我已完成登录」读取会话；「登录遇到问题？」折叠区提供手动会话令牌入口。保存的会话令牌由当前用户的文本保护器加密，退出登录清除应用保存的会话，本地查询记录保留。

查询可使用 Hexdata 绑定身份或用户输入的游戏 ID；查询自己时若绑定身份不可用，会尝试当前本机 LOL 账号。分数、收集状态、近期对局和双方玩家信息来自 Hexdata 返回的报告；界面不会为缺失或隐藏的玩家身份补造 ID。

查询报告缓存到本地，页面提供可展开的历史记录、对局列表、双方名单和按查询时间绘制的分数走势。查询详情中的游戏 ID 与双方名单玩家 ID 可选中复制。查询联网执行，查看已保存报告使用本地缓存。

评分库与 CLI 另提供表现分和团队 Elo 计算；桌面导航中的海斗分由 Hexdata 报告提供。

## 数据与生命周期

`AppPaths.CreateDefault()` 使用 `AppContext.BaseDirectory/userdata`。所需目录必须可写，失败时显示可操作的错误提示。开发和隔离验证可使用 `--data-root <路径>` 覆盖数据根。

设置页可分别配置数据根目录、当前空间数据库、设置文件和日志目录。目标路径先显示在界面，退出时复制最终数据并提交位置记录，下次启动使用新位置。源数据保留，已有目标不会直接覆盖；失败时保留原位置并提示重试。

若 `desktop-settings.json` 中 `minimizeToTray` 开启（Windows 默认开启），最小化和关闭窗口将隐藏至系统托盘，实时检测继续运行；托盘菜单「退出」结束进程并关闭数据库。该偏好立即生效并保存。安装器与卸载器保留用户数据。

备注、玩家游戏 ID、稳定身份和草稿使用 CurrentUser DPAPI，密文带 `dpapi1:` 前缀；保存的 Hexdata 会话令牌同样使用文本保护器。类别、时间等元数据以及 Hexdata 查询报告不是整库加密。同机快照恢复校验 schema、完整性、空间标识与加密键；恢复要求同一电脑与 Windows 用户。空间操作使用工作区租约并串行切换，防止写入其他账号数据库。

## 项目结构

| 项目 | 用途 |
| --- | --- |
| `LoLKarmaBook.Client` | 本机客户端发现、HTTPS、账号/阶段/名单解析和会话生命周期 |
| `LoLKarmaBook.Desktop` | WPF 页面、空间切换、实时检测、草稿、设置与数据路径 |
| `LoLKarmaBook.Core` | 笔记、身份与提醒规则 |
| `LoLKarmaBook.Storage` | SQLite 与一致性备份恢复 |
| `LoLKarmaBook.Hexdata` | Hexdata 客户端、登录会话、查询报告和本地缓存 |
| `LoLKarmaBook.Scoring` | 表现分与团队 Elo 计算 |
| `LoLKarmaBook.Riot` | Riot API 查询与对局解析 |
| `LoLKarmaBook.Cli` | 命令行示例、评分和数据验证 |

## 构建与发布验证

`scripts/verify.ps1`（或 `verify.sh`）构建解决方案，运行 Core、Scoring、Integration、Riot、Desktop Logic、Client 和 Paths 控制台断言套件，再比对评分参考数据。`Client.Tests --probe-local` 连接实际运行客户端，仅输出连接状态、账号识别结果、人数等匿名统计。

`scripts/installer-windows.ps1` 构建 Windows 自包含发布目录并调用 Inno Setup，输出 `LoLKarmaBook-1.0.0-windows-x64-setup.exe` 与同名 `.sha256`。打包过程检查版本与目录内容，拒绝将用户数据库、日志、备份或测试数据打入安装器。

`scripts/windows-smoke.ps1` 使用显式隔离数据根检查发布程序的窗口启动、建库与退出；`--smoke` 模式关闭实时检测。正常启动用于验证真实账号连接、客户端生命周期和交互。布局验收需覆盖默认窗口、最小窗口、缩窄后放宽，以及表单、记录菜单、设置折叠区和海斗分文本复制。
